# rock-paper-scissors-game

This is the revisited Rock paper scissors game for The odin project. This game has a UI with so it can be played on a webpage using buttons for each of the selections and the user can see the running score and outcome of round/game as well. This project showcases my current knowledge of basic js interworkings and also event listeners and interacting with the DOM. I have included,variables, functions, methods, if else statements and event listners to achieve this goal.
